# AP Scout

Wi-Fi access point finder and troubleshooting tool for Windows, by Dialsoft LLC (theITguy.com).

## Download

**[⬇ Download AP Scout (latest)](https://github.com/Dialsoft/apscout-releases/raw/main/APScout.exe)** — current version: **2.1.1**

Run it from a folder you can write to (Desktop, Downloads, or `C:\Tools`), not Program Files, so it can update itself.

Once installed, AP Scout checks this page every 6 hours and offers new versions automatically. Each update is verified against `APScout.exe.sha256` before it installs.

## What's new in 2.1.1

- Auto-update: AP Scout checks for new versions every 6 hours and offers to install them (checksum verified).
- Full Exit: the ⏻ button, Settings › Exit AP Scout, or Ctrl+Q shut it down completely.
- Group SSIDs by AP, plain-English Drops card with a Clear button, health-colored animated border on the connected card.
- Wi-Fi driver hardware ID shown to make driver lookups easy.
